# User Flow — RPFMS

## 1. เริ่มใช้งานครั้งแรก
```
เปิดเว็บ → /login → "ยังไม่มีบัญชี? ลงทะเบียน" → /register
  → กรอกชื่อ/อีเมล/รหัสผ่าน → ระบบสร้างบัญชี (role: USER)
  → ผู้ดูแลหลัก/แอดมิน เพิ่มผู้ใช้เข้าโครงการผ่าน /projects/[id] → Tab สมาชิก → เชิญด้วยอีเมล + กำหนดสิทธิ์ (OWNER/EDITOR/VIEWER)
  → ผู้ใช้ล็อกอิน → เห็นเฉพาะโครงการที่ตนมีสิทธิ์ (ยกเว้น ADMIN/SUPER_ADMIN เห็นทั้งหมด)
```

## 2. สร้างโครงการวิจัยใหม่ + ตั้งงบประมาณ
```
/projects → "สร้างโครงการใหม่" → กรอกข้อมูลโครงการ (ชื่อ/หัวหน้าโครงการ/หน่วยงาน/แหล่งทุน/ปีงบ/วันที่/งบรวม)
  → บันทึก → เข้าไปที่ /projects/[id] → Tab หมวดงบประมาณ → เพิ่มหมวด (ตอบแทน/ใช้สอย/วัสดุ/... หรือหมวดที่ตั้งเอง) พร้อมวงเงินที่จัดสรร
  → Tab กิจกรรม (Work Package) → แบ่งงบเป็นกิจกรรมย่อยตามแผนดำเนินงาน (ถ้ามีหลายกิจกรรม)
  → Tab รายรับ → บันทึกเงินงวดที่ได้รับจากแหล่งทุน
```

## 3. เบิกจ่ายเงิน (เจ้าหน้าที่การเงิน)
```
/expenses/new → เลือกโครงการ + หมวดงบ → กรอกวันที่/รายละเอียด/จำนวนเงิน/ผู้รับเงิน/วิธีชำระ
  → แนบไฟล์ใบเสร็จ (PDF/JPG) → กด "อ่านข้อมูลจากไฟล์ (OCR)"
      → ระบบ OCR + heuristic ดึง วันที่/จำนวนเงิน/เลขที่เอกสาร มาเสนอ พร้อมค่าความมั่นใจ
      → ผู้ใช้ตรวจสอบ แก้ไขถ้าจำเป็น แล้วกด "ใช้ค่านี้" ทีละช่อง (human-in-the-loop เสมอ)
  → บันทึกเป็นแบบร่าง (DRAFT) → กด "ส่งขออนุมัติ" → สถานะเปลี่ยนเป็น PENDING_STAFF
```

## 4. เวิร์กโฟลว์อนุมัติ
```
PENDING_STAFF → เจ้าหน้าที่การเงินตรวจสอบใน /approvals → อนุมัติ (พร้อมความเห็น) → PENDING_LEAD
PENDING_LEAD  → หัวหน้าโครงการตรวจสอบใน /approvals → อนุมัติ → APPROVED
APPROVED      → ผู้มีสิทธิ์ทำจ่ายจริง กด "ปิดรายการ/จ่ายแล้ว" → PAID
ทุกขั้นตอน: กด "ไม่อนุมัติ" ได้ พร้อมต้องระบุความเห็น → REJECTED → ผู้เบิกแก้ไขแล้วส่งใหม่ได้
```

## 5. ติดตามงบประมาณ
```
/ (Dashboard) → ดูภาพรวมงบรวม/ใช้แล้ว/คงเหลือ/กราฟรายเดือน/หมวด/โครงการ
/analytics → เลือกโครงการ → ดู Burn rate เทียบแผน, % การใช้งบ, หมวดที่ใช้จ่ายสูงสุด
ระบบแจ้งเตือนอัตโนมัติ (รายวัน) เมื่อ: งบเกิน 80%, งบเกินวงเงิน, มีรายการค้างอนุมัติ >3 วัน, โครงการใกล้สิ้นสุด <30 วัน
  → ผู้ใช้เห็น badge ที่กระดิ่ง → คลิกไปหน้า /notifications หรือรายการที่เกี่ยวข้องโดยตรง
```

## 6. ปิดงวด/ทำรายงานส่งผู้บริหารหรือแหล่งทุน
```
/reports → เลือกประเภทรายงาน (รายรับ/รายจ่าย/งบคงเหลือ/แยกโครงการ/แยกหมวด/รายเดือน/รายปี)
  → ตั้งตัวกรอง (โครงการ/ช่วงวันที่) → กด Export PDF/Excel/CSV → ไฟล์ดาวน์โหลดทันที
```
