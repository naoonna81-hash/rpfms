# คู่มือการใช้งาน — RPFMS (ระบบบริหารบัญชีโครงการวิจัย)

## 1. เข้าสู่ระบบ / ลงทะเบียน
- ไปที่หน้าเว็บระบบ → กรอกอีเมลและรหัสผ่าน → กด "เข้าสู่ระบบ"
- หากยังไม่มีบัญชี กด "ลงทะเบียน" กรอกชื่อ-นามสกุล อีเมล และตั้งรหัสผ่าน จากนั้นแจ้งผู้ดูแลโครงการให้เพิ่มสิทธิ์เข้าถึงโครงการที่เกี่ยวข้อง (ดูข้อ 6)

## 2. หน้าแดชบอร์ด
เมื่อเข้าสู่ระบบจะเห็นภาพรวมทันที: จำนวนโครงการ, งบประมาณรวม, งบที่ใช้แล้ว, งบคงเหลือ, จำนวนรายการเบิก พร้อมกราฟยอดใช้จ่ายรายเดือน กราฟสัดส่วนตามหมวดหมู่ และกราฟเปรียบเทียบงบตามโครงการ สามารถเลือกปีงบประมาณที่มุมขวาบนเพื่อกรองข้อมูล

## 3. จัดการโครงการวิจัย
- เมนู "โครงการวิจัย" → กด "สร้างโครงการใหม่" กรอกชื่อโครงการ (ไทย/อังกฤษ), หัวหน้าโครงการ, หน่วยงาน, ปีงบประมาณ (กรอกเป็น พ.ศ. เช่น 2569), วันที่เริ่ม-สิ้นสุด, งบประมาณรวม
- คลิกที่โครงการเพื่อเข้าไปตั้งค่ารายละเอียด:
  - **หมวดงบประมาณ**: เพิ่มหมวดที่ต้องการ (ค่าตอบแทน, ค่าใช้สอย, ค่าวัสดุ, ค่าเดินทาง, ค่าครุภัณฑ์, ค่าอบรม, ค่าเผยแพร่ผลงาน, หรือหมวดที่ตั้งชื่อเอง) พร้อมวงเงินที่จัดสรร
  - **กิจกรรม (Work Package)**: ใช้เมื่อมีการแบ่งงบเป็นหลายกิจกรรมย่อยตามแผนดำเนินงาน
  - **รายรับ**: บันทึกเงินที่ได้รับจากแหล่งทุนแต่ละงวด
  - **สมาชิก**: เชิญผู้ใช้อื่นเข้าถึงโครงการนี้ด้วยอีเมล พร้อมกำหนดสิทธิ์ (เจ้าของ/แก้ไขได้/ดูอย่างเดียว)

## 4. บันทึกรายการเบิกจ่าย (พร้อม OCR อ่านใบเสร็จอัตโนมัติ)
1. เมนู "ระบบเบิกจ่าย" → "สร้างรายการเบิก"
2. เลือกโครงการและหมวดงบ กรอกวันที่ รายละเอียด จำนวนเงิน ผู้รับเงิน วิธีชำระ
3. แนบไฟล์ใบเสร็จ/ใบสำคัญ (PDF, JPG, PNG) แล้วกดปุ่ม "อ่านข้อมูลจากไฟล์"
4. ระบบจะแสดงวันที่ จำนวนเงิน และเลขที่เอกสารที่ตรวจพบ พร้อมระดับความมั่นใจ — **ให้ตรวจสอบความถูกต้องก่อนเสมอ** แล้วกด "ใช้ค่านี้" ในช่องที่ถูกต้อง เนื่องจากเป็นระบบผู้ช่วยเบื้องต้น ไม่ใช่การกรอกอัตโนมัติ 100%
5. กด "บันทึกแบบร่าง" เพื่อแก้ไขภายหลัง หรือ "ส่งขออนุมัติ" เพื่อเข้าสู่ขั้นตอนอนุมัติทันที

## 5. การอนุมัติ
- รายการที่ส่งขออนุมัติจะผ่าน 3 ขั้นตอนตามลำดับ: **เจ้าหน้าที่การเงิน → หัวหน้าโครงการ → ปิดรายการ/จ่ายเงิน**
- เมนู "ระบบอนุมัติ" แสดงรายการที่รอการอนุมัติจากท่าน กดปุ่ม "อนุมัติ" หรือ "ไม่อนุมัติ" พร้อมระบุความคิดเห็นได้ทุกครั้ง
- หากถูกตีกลับ (ไม่อนุมัติ) ผู้เบิกสามารถแก้ไขรายการและส่งขออนุมัติใหม่ได้

## 6. การแชร์สิทธิ์ให้ผู้อื่นเข้าถึงโครงการ
เข้าไปที่โครงการ → แท็บ "สมาชิก" → กรอกอีเมลผู้ที่ต้องการเชิญ → เลือกสิทธิ์:
- **เจ้าของ (OWNER)**: แก้ไข อนุมัติ และจัดการสิทธิ์ผู้อื่นได้
- **แก้ไขได้ (EDITOR)**: เพิ่ม/แก้ไขรายการเบิก-รับได้ แต่อนุมัติไม่ได้
- **ดูอย่างเดียว (VIEWER)**: ดูข้อมูลได้เท่านั้น
ผู้ถูกเชิญต้องมีบัญชีในระบบ (ลงทะเบียนด้วยอีเมลนั้นก่อน) จึงจะเข้าถึงได้

## 7. รายงานและการส่งออกข้อมูล
เมนู "รายงาน" → เลือกประเภทรายงาน (รายรับ/รายจ่าย/งบคงเหลือ/แยกโครงการ/แยกหมวด/รายเดือน/รายปี) → ตั้งตัวกรองโครงการและช่วงวันที่ → กดปุ่ม Export เป็น PDF, Excel หรือ CSV ตามต้องการ

## 8. วิเคราะห์งบประมาณ
เมนู "วิเคราะห์งบประมาณ" → เลือกโครงการ → ดู Burn Rate (อัตราการใช้จ่ายจริงเทียบแผน), % การใช้งบ, และหมวดที่ใช้จ่ายสูงสุด เพื่อประกอบการตัดสินใจบริหารงบ

## 9. การแจ้งเตือน
กระดิ่งที่มุมขวาบนแสดงจำนวนแจ้งเตือนที่ยังไม่อ่าน ระบบจะแจ้งเตือนอัตโนมัติเมื่อ: งบใช้เกิน 80%, งบเกินวงเงินที่ตั้งไว้, มีรายการค้างอนุมัติเกิน 3 วัน, หรือโครงการใกล้ครบกำหนดภายใน 30 วัน

## 10. ค้นหาข้อมูล
เมนู "ค้นหา" หรือช่องค้นหาบน Top navigation — ค้นได้จากชื่อโครงการ รหัสโครงการ ชื่อนักวิจัย หมวดงบ ปีงบประมาณ หรือช่วงวันที่

## 11. ตั้งค่าบัญชี
เมนู "ตั้งค่า" → แก้ไขโปรไฟล์/เปลี่ยนรหัสผ่าน ผู้ดูแลระบบ (Admin/Super Admin) จะเห็นเมนูจัดการผู้ใช้งานทั้งหมดเพิ่มเติม

## 12. โหมดมืด/สว่างและการใช้งานบนมือถือ
กดไอคอนพระจันทร์/พระอาทิตย์บน Top navigation เพื่อสลับโหมด ระบบรองรับการใช้งานเต็มรูปแบบบนคอมพิวเตอร์ แท็บเล็ต และมือถือ (เมนูจะปรับเป็นแถบด้านล่างบนหน้าจอมือถือ)

**หมายเหตุด้านความปลอดภัย**: กรุณาเปลี่ยนรหัสผ่านทันทีหลังเข้าใช้งานครั้งแรกด้วยบัญชีตัวอย่างที่ได้รับ และไม่แชร์รหัสผ่านร่วมกันระหว่างผู้ใช้หลายคน
